## 🚀 Featured Projects

### 🧮 معلّمي · Moalemi — Arabic Math Learning for Kids
A game-like math platform following the **Palestinian curriculum**. Lessons are organized as "islands" (numbers, addition, subtraction, shapes, measurement, time…), each grade with its own world and design.
- ✅ Grades 1–6 live · roadmap through Tawjihi
- 🎮 Interactive, Arabic-Indic numerals, mobile-friendly
- 🛠 React · Vercel
- 🔗 **Live:** [moalem-math.vercel.app](https://moalem-math.vercel.app)

### 💍 زفاف · Zafaf — Wedding Services Marketplace for Gaza
A multi-vendor platform where brides browse halls, dresses, photography, decoration, cars and more in one place, and contact vendors directly on WhatsApp.
- 👰 Free for brides · vendor pages + subscription model
- 📋 Bride's wedding assistant: budget-based vendor suggestions
- 🛠 React · Netlify
- 🔗 **Live:** [zafaf-wedding.netlify.app](https://zafaf-wedding.netlify.app) · **Code:** [wedding-](https://github.com/HadeelAlwadia/wedding-)

### 🏥 Aura Clinic — Clinical Management Suite
A management platform for medical aesthetic centers: automated booking, staff scheduling and patient records.
- ⚙️ Workflow automation · clean UI/UX · built to scale
- 🛠 React · Node.js · Express · MongoDB
- 🔗 **Live:** [front-end-system-weld.vercel.app](https://front-end-system-weld.vercel.app)
